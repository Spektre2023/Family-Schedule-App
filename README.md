# Family Schedule (Option A — Trips per Day)

This build supports **multiple trips per day** (morning + afternoon etc).

## Dad view
- Default is **Dad (Read)** mode.
- Tap **Today** for a big, simple view.
- Tap **Week** for a quick overview.
- Tap a day in Week to open that day’s details.

## Edit view
- Tap the **Dad (Read)** button to switch to **Edit**.
- If you set a PIN in Settings, tap **Unlock Edit** and enter the PIN.
- Add unlimited trips per day.
- Reorder trips with ↑ / ↓.
- Locations are shared between **From** and **Drop off**.

## GitHub Sync (optional)
GitHub Pages is static. To let Ester edit on iPhone and save back to GitHub:
1. Create a **fine‑grained token** (Repo access only for this repo)
2. Permissions: **Contents = Read & Write**
3. In the app: Settings → paste token + repo details → Save
4. Sync → Save to GitHub

Dad does NOT need a token — he just refreshes to see updates.
